# SillyTavern - Doom's Enhancement Suite - RU

Надстройка для SillyTavern поверх [Doom's Enhancement Suite](https://github.com/DangerDaza/Dooms-Enhancement-Suite) (DES):
русский интерфейс DES и исправления трекера для ролеплея на русском. Плюс лорбуки
[BunnyMo](https://github.com/Coneja-Chibi/BunnyMo) и расширение [CarrotKernel](https://github.com/Coneja-Chibi/CarrotKernel),
которые без неё в русской игре работают наполовину.

> **Это надстройка, а не форк.** В репозитории нет кода DES, CarrotKernel и лорбуков BunnyMo, и ни один их файл
> не меняется. Они ставятся и обновляются отдельно, из своих репозиториев. Надстройка работает с ними через DOM,
> события SillyTavern и публичные экспорты их модулей.

**📖 Подробная инструкция — в [docs/guide](docs/guide/README.md).**

## Что умеет

| Модуль | Коротко | Инструкция |
|---|---|---|
| 1. Локализация интерфейса | Весь интерфейс DES по-русски: настройки, окна, «Мастерская», лист персонажа, трекер сцены, уведомления. Свой словарь и выгрузка непереведённого | [подробнее](docs/guide/module-1-localization.md) |
| 2. Имена персонажей | «Ани», «Капитан Аня», «Анечка», «Anya» не превращаются в дубли персонажа «Аня». Раскраска реплик и пузыри для русских имён, листы под именем карточки | [подробнее](docs/guide/module-2-names.md) |
| 3. Служебные значения | Эффекты погоды и смена дня и ночи работают с русскими значениями: «моросит», «вьюга», «безоблачно» | [подробнее](docs/guide/module-3-service-values.md) |
| 4. Исправления DES для русского | Кириллические названия полей, «не в сцене», «квеста нет», переводы встроенного переводчика ST | [подробнее](docs/guide/module-4-fixes.md) |
| 5. BunnyMo по-русски | Детекторы и архивы BunnyMo видят русский текст и падежи, листы выходят по-русски с английскими тегами, паки срабатывают | [подробнее](docs/guide/module-5-bunnymo.md) |
| 6. CarrotKernel по-русски | CK не путает персонажей с русскими именами, его дамп тегов не мешает модели и DES, «умный контекст» находит листы по падежам, интерфейс CK по-русски | [подробнее](docs/guide/module-6-carrotkernel.md) |

Модули и их части включаются переключателями в [панели надстройки](docs/guide/panel.md).

## Требования

- **SillyTavern 1.19.x.**
- **Doom's Enhancement Suite** — для модулей 1–4. Проверено на 2.6.0 (коммит `10ad241`).
- По желанию: **лорбуки BunnyMo** (проверено на V3.0 и паках «BunnMo Packs») — для модуля 5, и **CarrotKernel**
  (проверено на 1.0.0) — для модуля 6.

## Быстрый старт

1. Поставьте DES: **Extensions** → **Install Extension** → `https://github.com/DangerDaza/Dooms-Enhancement-Suite`.
2. Поставьте надстройку тем же способом:
   ```
   https://github.com/Likerch/SillyTavern-Doom-Enhancement-Suite-RU
   ```
3. Перезагрузите страницу. В **Extensions**, под блоком DES, появится панель надстройки со статусом «работает».
4. В настройках DES выберите режим генерации **«Вместе с ответом»**: в нём работают все возможности.

Подробно — в [Установке](docs/guide/installation.md), а как играть со всем набором — в [Как играть](docs/guide/playing.md).

## Совместимость

- **Режимы DES.** Всё работает в режиме «Вместе с ответом». В «Отдельным запросом» и «Внешний API» нет склейки форм
  имён и подсказок модели, остальное работает. Подробнее — в [таблице](docs/guide/compatibility.md#режимы-des).
- **Qvink Memory** совместим. Как настроить его для русской игры с DES — в
  [Совместимости](docs/guide/compatibility.md#qvink-memory).
- **NAI Studio** — с версии 0.9.3. **LorebookLocalizer** — совместим.

## Приватность

Никакой телеметрии и внешних запросов. Сама надстройка загружает только свои словари с того же сервера SillyTavern.
Настройки хранятся в `extension_settings.desru`. Что надстройка записывает в данные DES и CK, перечислено в
[Совместимости](docs/guide/compatibility.md#что-надстройка-меняет).
