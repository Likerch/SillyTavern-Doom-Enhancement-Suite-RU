# SillyTavern - Doom's Enhancement Suite - RU

Надстройка для SillyTavern поверх [Doom's Enhancement Suite](https://github.com/DangerDaza/Dooms-Enhancement-Suite) (DES):
русский интерфейс DES и исправления трекера для ролеплея на русском.

> **Это надстройка, а не форк.** В репозитории нет кода DES, и ни один его файл не меняется.
> DES ставится и обновляется отдельно, из своего репозитория. Надстройка работает с ним
> через DOM, события SillyTavern и публичные экспорты его ES-модулей.

**Статус:** в разработке. Готовы модули 1, 3 и 4; модуль 2 «Нормализация имён» пока заглушка.

## Модули

| № | Модуль | Состояние |
|---|---|---|
| 1 | Локализация интерфейса DES | готов |
| 2 | Нормализация имён (падежи → алиасы DES) | заглушка |
| 3 | Служебные значения (погода, время суток) | готов |
| 4 | Исправления DES для русского | готов |

Модуль 1 переводит интерфейс DES — настройки, окна, мастерскую, лист персонажа, трекер сцены,
пузыри, мысли, уведомления, всего около 1100 строк. Данные не трогает: имена, значения трекера,
текст чата и лорбуки остаются как есть. Перевод накладывается поверх страницы, поэтому выключенный
модуль сразу возвращает английский, без перезагрузки.

- **свой словарь** в панели («английская строка → перевод») перекрывает встроенный и переводит подписи своих полей трекера;
- **непереведённые строки** (например, после обновления DES) собираются и выгружаются в JSON в формате словаря;
- переключатели: переводить ли уведомления DES и собирать ли непереведённое.

Модуль 3 нужен, чтобы эффекты погоды DES (дождь, снег, туман, солнце и луна) работали на русском.
Значения в трекере он не меняет. Каждая часть включается отдельно:

- **русская погода для эффектов DES**: DES понимает только базовые слова вроде «дождь» и «туман», а «дождливо», «моросит»,
  «вьюга», «безоблачно» пропускает. Модуль дописывает такие формы в словарь погоды DES — только в памяти и ещё до
  того, как ST откроет чат. Слова можно править в панели, там же можно проверить, как DES поймёт прогноз;
- **погода по-русски в промпте**: DES просит модель писать погоду одним английским словом; модуль просит одно русское
  слово из списка, который DES понимает;
- **время как ЧЧ:ММ**: по часам DES решает, день сейчас или ночь. Русские «вечер» или «ночь» он не понимает.

Подсказки модели работают в режиме DES «Вместе с ответом». Для режимов «Отдельным запросом» и «Внешний API» в панели
есть готовый текст для редактора промптов DES.

Модуль 4, каждое исправление включается отдельно:

- **кириллические названия полей персонажа** («Внешность», «Поведение»): DES превращает их в пустые ключи `""` шаблона трекера, надстройка возвращает названия (режим together);
- **«не в сцене» по-русски**: «не присутствует в сцене», «вне сцены», «за кадром» в мыслях персонажа → DES показывает его отсутствующим;
- **«Нет» вместо квеста**: «Нет», «Отсутствует», «—» → служебное «квеста нет»;
- **переводы встроенного переводчика ST**: DES стирает их при каждой смене чата, надстройка их сберегает.

Что снаружи не исправить, собрано в [docs/upstream-issues.md](docs/upstream-issues.md) — это готовые тексты issue для DES.

## Требования

- SillyTavern 1.19.x;
- установленный и включённый Doom's Enhancement Suite (проверено на 2.6.0). Без DES надстройка тихо ничего не делает.

## Установка

Extensions → Install Extension → URL репозитория:

```
https://github.com/Likerch/SillyTavern-Dooms-Enhancement-Suite-RU
```

Подробная инструкция, описание модулей и «что делать, когда DES обновился» появятся на последнем этапе.

## Разработка

- `vendor/des` — клон DES только для чтения; используется для разведки и не попадает в git.
- `docs/des-recon.md` — разведка DES: селекторы, стейт, точки интеграции.
- `docs/manual-test.md` — чек-лист ручной проверки после каждого этапа.
- `npm test` — тесты чистой логики (Node 20+, без зависимостей).
- `locales/ru.json` — встроенный словарь; `node tools/check-dictionary.mjs` проверяет дубли, плейсхолдеры и теги.
- `node tools/extract-des-strings.mjs vendor/des --missing locales/ru.json` — строки из JS-кода DES, которых нет
  в словаре; `--stale locales/ru.json` — ключи словаря, которых больше нет в DES. Оба отчёта смотреть глазами:
  в первом попадаются промпты и куски уже переведённых подсказок, во втором — строки, которые DES склеивает из частей.
