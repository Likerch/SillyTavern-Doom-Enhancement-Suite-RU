# Совместимость и что где меняется

[← Оглавление](README.md)

## Режимы DES

Режим генерации DES — «Вместе с ответом», «Отдельным запросом» или «Внешний API» — меняет, до чего надстройка
дотягивается. Удобнее всего «Вместе с ответом»: в нём работает всё.

| Возможность | «Вместе с ответом» | «Отдельным запросом», «Внешний API» |
|---|---|---|
| Модуль 1: перевод интерфейса | да | да |
| Модуль 2: склейка форм имён и формы имени игрока | да | нет — о похожих именах спрашивает попап DES |
| Модуль 2: регистр и ё, раскраска реплик, листы | да | да |
| Модуль 3: словарь погоды | да | да |
| Модуль 3: подсказки модели (погода, время) | да | нет — в панели есть готовый текст для редактора промптов DES |
| Модуль 4: кириллические названия полей | да | нет — назовите поля латиницей |
| Модуль 4: «не в сцене», «квеста нет», переводы | да | да |
| Модули 5 и 6 | да | да — от режима DES не зависят |

Если какая-то возможность в текущем режиме не работает, модуль сам предупредит об этом замечанием в панели.

## Другие расширения

### Qvink Memory

[Qvink Memory](https://github.com/qvink/SillyTavern-MessageSummarize) пересказывает каждое сообщение и подставляет
пересказы вместо старых сообщений. С надстройкой совместим. Пересказы Qvink шлёт отдельным запросом, без пресета,
лорбуков и вставок DES, CK и надстройки, поэтому ни языковой замок, ни подсказки DES туда не попадают. Значит,
промпт Qvink нужно настроить самому. Для русской игры с DES хорошо работает так:

- **Свой профиль подключения и пресет для пересказов.** Низкая температура, около 0.3. Рассуждения выключены:
  в пресете «Reasoning Effort» — «Минимум», «Показывать мысли» снят. Без стриминга и инструментов, лимит ответа —
  1–2 тысячи токенов. Выберите этот профиль в Qvink → Summarization → Connection Profile. Иначе Qvink возьмёт пресет
  чата с его лимитом и рассуждениями.
- **Промпт на русском.** Английский по умолчанию даёт английские пересказы с именами латиницей. Например:
  ```
  Ты пересказываешь ролевую историю. Перескажи сообщение ниже одним–тремя короткими предложениями: только что произошло, без оценок и украшений.

  Правила:
  - Пиши по-русски, в прошедшем времени, от третьего лица.
  - Называй персонажей по именам, как в тексте. {{user}} — персонаж игрока.
  - Сохраняй главное: поступки и важные слова, решения и обещания, раскрытые тайны, перемены в отношениях, раны и важные предметы, смену места и времени.
  - Пропускай служебное: трекеры, панели и статистику, разметку.
  - Если событий нет (например, это лист персонажа), напиши одно предложение о том, что это.
  - В ответе — только пересказ, без вступлений и пояснений.

  {{#if history}}
  Что было прямо перед этим — для контекста. Строки «Summary:» — уже готовые пересказы, не повторяй их. Если сообщение отвечает на реплику {{user}}, коротко упомяни поступок или слова {{user}}.
  {{history}}
  {{/if}}

  Сообщение, которое нужно пересказать:
  {{message}}
  ```
- **Очистка текста перед пересказом.** В режиме «Вместе с ответом» DES оставляет JSON трекера в тексте сообщения и
  прячет его только своей регуляркой. В редакторе промпта Qvink, у макросов `{{message}}` и `{{history}}`, выберите
  в поле Regex регулярки DES «Remove Tracker JSON (Together Mode)» и «Clean HTML (From Outgoing Prompt)», если она есть.
- **Макрос `{{history}}`**: диапазон 1–2, только реплики пользователя и пересказы ответов, без Separate Block. Так в
  пересказ попадёт и то, что сделал игрок: свои сообщения Qvink отдельно не пересказывает.
- **Вставка:** Injection Threshold — около 20 сообщений, Remove Messages включён. Шаблоны вставки — тоже по-русски,
  например «[Что произошло раньше — пересказ по порядку]:».
- **Автопересказ:** Message Lag — 2: последние ответы ещё могут свайпнуть. Message Limit — **−1**, без предела:
  при 0 Qvink сам поставит 1. Parallel summaries — 1: тогда каждый пересказ видит предыдущий.
- **Include in WI Scan** выключен: лорбуки и так сканируют последние сообщения.
- В уже идущих длинных чатах перед следующим сообщением выполните `/qm-summarize-chat`. Иначе первый ответ уйдёт
  без старой истории.
- Если пользуетесь **NAI Studio**, нужна версия **0.9.3 или новее**. Раньше NAI Studio возвращал в промпт сообщения с
  картинками, которые Qvink уже заменил пересказами.

### NAI Studio

Совместим. Для работы вместе с Qvink Memory нужна NAI Studio 0.9.3 или новее, см. выше.

### LorebookLocalizer

Совместим. Если LorebookLocalizer уже переписал ключи лорбука регулярками со словоформами, модуль 5 такие ключи
не трогает. Он расширяет падежами только обычные кириллические ключи архивов персонажей.

### Регулярки, которые вырезают HTML из промпта

«Clean HTML (From Outgoing Prompt)», «html vanisher» и подобные вырезают из истории все `<теги>`, вместе с тегами BunnyMo.
Как оставить теги `<KEY:VALUE>` — в [модуле 5](module-5-bunnymo.md#регулярки-вырезающие-теги).

### Встроенный переводчик ST (Chat Translation)

DES стирает его переводы при каждой смене чата. Модуль 4 их бережёт —
[«Не давать DES стирать переводы»](module-4-fixes.md).

## Что надстройка меняет

| Что | Где | Насовсем? |
|---|---|---|
| Переводы интерфейса | только на странице | нет — выключение модуля 1 возвращает английский |
| Правки вёрстки под русский текст | только на странице | нет — снимаются вместе с модулем 1 |
| Слова погоды | словарь DES в памяти | нет — до перезагрузки страницы |
| Шаблон трекера (погода, время, имена, названия полей) | только в запросе к модели | нет |
| Другие имена (алиасы) персонажей | настройки DES (`characterAliases`) — общие на все чаты | да — видны в «Мастерской» DES, склейки отменяются «Разъединить» |
| Формы имени игрока, скрытые из «Персонажей в сцене» | DES (`removedCharacters`), в своём чате | да — отменяются «Разъединить» в том же чате |
| Цвета реплик русских персонажей | DES (`characterColors`) | да — как если бы их связал сам DES |
| Листы под именем карточки | чат (`characterSheets` DES) | да — лист под длинным именем не остаётся; уже записанный у карточки обновляется только более новым импортом |
| «Не в сцене», «квеста нет» | данные трекера в чате | да — как если бы модель сразу написала так, как понимает DES |
| Служебные токены BunnyMo в ответе («Раздел 1 из 8» → `SECTION 1/8:`) | текст ответа в чате | да — проза не меняется |
| Правки записей BunnyMo (ключи, флаги рекурсии, текст Alpha) | только в сканировании лорбуков | нет — файлы лорбуков не меняются |
| Языковой замок, теги сцены для паков | вставки в промпт | нет; теги сцены хранятся в чате (`desru_bunnymo`) |
| Вставка тегов CK, дамп CK в истории | только в запросе к модели | нет |
| Поиск персонажа в листах и макросах CK | память CK | до перезагрузки страницы |
| Падежные формы имён в триггерах RAG CK | настройки CK (`rag.collectionMetadata`) | да — убираются выключением «RAG по падежам имени» |

Свои настройки надстройка хранит в `extension_settings` под ключом `desru`.
