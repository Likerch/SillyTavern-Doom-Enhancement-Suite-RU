# Инструкция

Подробное руководство по надстройке **SillyTavern - Doom's Enhancement Suite - RU**: что она умеет, как её поставить
и настроить и как с ней играть. Короткое описание — в [README](../../README.md) репозитория.

Надстройка работает поверх [Doom's Enhancement Suite](https://github.com/DangerDaza/Dooms-Enhancement-Suite) (DES)
и по желанию — поверх лорбуков [BunnyMo](https://github.com/Coneja-Chibi/BunnyMo) и расширения
[CarrotKernel](https://github.com/Coneja-Chibi/CarrotKernel) (CK). Ни один их файл она не меняет.

## С чего начать

1. [Установка и обновление](installation.md) — требования, установка, первая проверка, обновление и удаление.
2. [Панель надстройки](panel.md) — где она, что значат статусы и замечания, как включать модули и их части.
3. [Как играть](playing.md) — порядок работы с DES, BunnyMo и CarrotKernel: от новой карточки до долгой игры.

## Модули

| Модуль | Что делает |
|---|---|
| [1. Локализация интерфейса](module-1-localization.md) | Весь интерфейс DES по-русски; свой словарь и выгрузка непереведённого |
| [2. Имена персонажей](module-2-names.md) | Падежи, звания, уменьшительные и латиница не плодят дубли персонажей; раскраска реплик; листы под именем карточки |
| [3. Служебные значения](module-3-service-values.md) | Эффекты погоды и смена дня и ночи работают с русскими значениями |
| [4. Исправления DES для русского](module-4-fixes.md) | Кириллические названия полей, «не в сцене», «квеста нет», переводы встроенного переводчика ST |
| [5. BunnyMo по-русски](module-5-bunnymo.md) | Детекторы, архивы и паки BunnyMo работают с русским текстом; листы по-русски с английскими тегами |
| [6. CarrotKernel по-русски](module-6-carrotkernel.md) | Правильные теги у персонажей с русскими именами, дамп CK не мешает, RAG по падежам, интерфейс CK по-русски |
