# Ручная проверка

Чек-лист проходится после каждого этапа на живом ST. Автотестов на DOM нет; чистая логика
покрыта `npm test`. В консоли браузера все сообщения надстройки начинаются с `[DES-RU]`.

Отметки: `[x]` — проверено, `[ ]` — не проверено, `[!]` — не прошло (описать ниже пункта).

## Этап 1 — скелет

Подготовка: SillyTavern 1.19.x, DES 2.6.0, надстройка установлена по URL репозитория.
Перед проверкой открыть консоль браузера (F12) и перезагрузить страницу.

### Установка и запуск
- [ ] В Extensions → Manage Extensions надстройка видна как «SillyTavern - Doom's Enhancement Suite - RU» v0.1.0.
- [ ] В консоли нет красных ошибок с `[DES-RU]` и нет ошибок ST вида «Extension … failed to load».
- [ ] В консоли есть строки `Запуск надстройки 0.1.0` и `Гард: DES 2.6.0 найден, проверки пройдены.`
- [ ] В правой колонке Extensions под блоком DES появился блок «SillyTavern - Doom's Enhancement Suite - RU».

### Панель
- [ ] Статус — зелёный «работает», под ним `third-party/Dooms-Enhancement-Suite · v2.6.0`, списков проблем нет.
- [ ] Все четыре модуля включены, у каждого — «включён (пока заглушка)».
- [ ] Выключить модуль 2 → статус «выключен»; перезагрузить страницу → модуль 2 так и остался выключен. Включить обратно.
- [ ] «Перепроверить DES» — бейдж на секунду показывает «проверяю…» и возвращается к «работает».
- [ ] «Журнал и отладка» → включить режим отладки → в журнале появилась строка «Режим отладки включён».
- [ ] «Скопировать» — в буфере текст журнала; «Очистить» — журнал пуст.
- [ ] Выключить режим отладки.

### DES не сломан
- [ ] Кнопка «D» на месте, панель настроек DES открывается.
- [ ] Present Characters и Scene Tracker выглядят и работают как без надстройки: отправить сообщение, дождаться ответа.
- [ ] После открытия настроек DES (первое открытие любого окна DES) в журнале надстройки нет предупреждений о селекторах.

### Деградация
- [ ] Выключить DES его собственным переключателем в блоке DES → через пару секунд статус надстройки «DES выключен», модули 2–4 «остановлен гардом», модуль 1 «включён». Включить DES обратно → статус снова «работает».
- [ ] Выключить DES в Manage Extensions и перезагрузить → статус «DES выключен», модули «не работает: DES недоступен», ошибок в консоли нет. Включить DES обратно и перезагрузить.
- [ ] (по желанию) Без DES вообще → статус «нет DES», ошибок нет.
