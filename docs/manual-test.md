# Ручная проверка

Чек-лист проходится после каждого этапа на живом ST. Автотестов на DOM нет; чистая логика
покрыта `npm test`. В консоли браузера все сообщения надстройки начинаются с `[DES-RU]`.

Отметки: `[x]` — проверено, `[ ]` — не проверено, `[!]` — не прошло (описать ниже пункта).

## Этап 1 — скелет

Подготовка: SillyTavern 1.19.x, DES 2.6.0, надстройка установлена по URL репозитория.
Перед проверкой открыть консоль браузера (F12) и перезагрузить страницу.

### Установка и запуск
- [ ] В Extensions → Manage Extensions надстройка видна как «SillyTavern - Doom's Enhancement Suite - RU» с текущей версией.
- [ ] В консоли нет красных ошибок с `[DES-RU]` и нет ошибок ST вида «Extension … failed to load».
- [ ] В консоли есть строки `Запуск надстройки <версия>` и `Гард: DES 2.6.0 найден, проверки пройдены.`
- [ ] В правой колонке Extensions под блоком DES появился блок «SillyTavern - Doom's Enhancement Suite - RU».

### Панель
- [ ] Статус — зелёный «работает», под ним `third-party/Dooms-Enhancement-Suite · v2.6.0`, списков проблем нет.
- [ ] Все четыре модуля включены; у ещё не реализованных — «включён (пока заглушка)», у готовых — «работает».
- [ ] Выключить модуль 2 → статус «выключен»; перезагрузить страницу → модуль 2 так и остался выключен. Включить обратно.
- [ ] «Перепроверить DES» — бейдж на секунду показывает «проверяю…» и возвращается к «работает».
- [ ] «Журнал и отладка» → включить режим отладки → в журнале появилась строка «Режим отладки включён».
- [ ] «Скопировать» — в буфере текст журнала; «Очистить» — журнал пуст.
- [ ] Выключить режим отладки.

### DES не сломан
- [ ] Кнопка «D» на месте, панель настроек DES открывается.
- [ ] Present Characters и Scene Tracker выглядят и работают как без надстройки: отправить сообщение, дождаться ответа.
- [ ] После открытия настроек DES (первое открытие любого окна DES) в журнале надстройки нет предупреждений о селекторах.

### Деградация
- [ ] Выключить DES его собственным переключателем в блоке DES → через пару секунд статус надстройки «DES выключен», модули 2–4 «остановлен гардом», модуль 1 «включён». Включить DES обратно → статус снова «работает».
- [ ] Выключить DES в Manage Extensions и перезагрузить → статус «DES выключен», модули «не работает: DES недоступен», ошибок в консоли нет. Включить DES обратно и перезагрузить.
- [ ] (по желанию) Без DES вообще → статус «нет DES», ошибок нет.

### Кириллические названия полей
- [ ] Отправить сообщение и дождаться ответа. В журнале надстройки появилась строка «в шаблон трекера возвращены названия полей «Внешность», «Поведение».»

- [ ] Если модель напишет в квесте «Нет» или «Отсутствует» (можно попросить вне роли): в Scene Tracker нет строки Quest, в журнале «квест «Нет» — квеста нет».

- [ ] Перезагрузить страницу и открыть тот же чат — перевод на месте.
- [ ] (по желанию) Контроль: выключить «Не давать DES стирать переводы», переключиться туда-обратно — перевод пропал: это баг DES. Включить обратно и перевести заново.

## Этап 3 — модуль 1 «Локализация интерфейса»

Подготовка: надстройка v0.3.0. Язык самого ST любой: ST переводит себя сам, надстройка трогает только DES.

### Панель
- [ ] У модуля 1 статус «работает», в журнале надстройки «Модуль 1 (локализация) включён: в словаре … строк».
- [ ] Раздел «Словарь интерфейса»: «В словаре … строк, своих — 0. Непереведённых встречено: …».
- [ ] Свой словарь: вписать `{ "Present Characters": "Кто в сцене" }` → «Сохранить словарь» → заголовок панели персонажей сменился сразу, без перезагрузки. Битый JSON → под полем ошибка, прежний словарь работает. Вернуть `{}` и сохранить.

### Интерфейс DES по-русски
- [ ] Меню кнопки «D»: пункты DES («Мастерская», «Настройки DES») по-русски, пункты ST — как в самом ST.
- [ ] Настройки DES: все 14 секций — заголовки, переключатели, подсказки, выпадающие списки.
- [ ] Окна из настроек: редактор трекера, редактор промптов, системный журнал, журнал уведомлений, инспектор генераций (обе вкладки), каталог персонажей, библиотека лора.
- [ ] Мастерская персонажа — все вкладки; лист персонажа — «Лист» и «Статистика».
- [ ] Чат: трекер сцены во всех раскладках (от «Сетка» до «Тикер снизу»), пузыри «Discord» и «Карточки», мысли, счётчик рока, окно «Что нового».
- [ ] Окно «Возможно, дубль персонажа» (появляется, когда модель называет знакомого персонажа иначе): текст и кнопки по-русски, «Да»/«Нет» работают.
- [ ] Уведомления: системный журнал → «Очистить» → «Системный журнал очищен.»; в настройках DES «Сбросить настройки» → текст окна подтверждения по-русски (нажать «Отмена»; кнопки окна — от ST, на его языке).

### Данные не тронуты
- [ ] Имена персонажей, значения трекера (место, погода, мысли), текст сообщений, названия лорбуков и записей — как были.
- [ ] Свои поля трекера: их подписи встроенный словарь не переводит (только свой).
- [ ] Лист персонажа → «Копировать»: в буфере исходный текст листа.

### Выключение
- [ ] Выключить модуль 1 → DES сразу по-английски, без перезагрузки; включить → снова по-русски.

### Сбор непереведённого
- [ ] Счётчик непереведённых растёт, только если в DES есть строка без перевода (после обновления DES). «Выгрузить непереведённые (JSON)» → скачивается `desru-untranslated.json` в формате словаря; «Очистить список» → счётчик 0.
- [ ] (по желанию) Выключить «Собирать непереведённые строки» → счётчик больше не растёт.

### Телефон
- [ ] На телефоне (окно уже 480 px): подписи ползунков в настройках не обрезаются многоточием; в редакторе промптов ряд «Вернуть встроенный · Глубина · Роль» переносится, а не уезжает за край; в редакторе трекера «Сброс · Экспорт · Импорт» в одну строку.

## Этап 5 — модуль 2 «Нормализация имён»

Подготовка: надстройка v0.5.0, режим генерации DES «Вместе с ответом», в чате есть персонаж, например «Аня».

### Склейка
- [ ] Попросить модель вне роли: «(OOC: в трекере назови Аню «Аней»)». После ответа в Present Characters одна карточка «Аня», попапа «Возможно, дубль персонажа» нет. В журнале надстройки «Имена: «Аней» → «Аня» (алиас DES)».
- [ ] То же для «Ани» (форма на одну букву: без модуля DES спросил бы попапом) и для «аня» (только регистр: без модуля DES молча заводит вторую карточку).
- [ ] Workshop DES → «Аня» → Identity → Aliases: там «Аней», «Ани», «аня».
- [ ] Context Inspector DES или журнал запросов: в шаблоне трекера `"name": "Имя в именительном падеже, как на карточке персонажа"`.

### Панель «Склейки имён»
- [ ] В списке склеек «Аней» → «Аня» с датой.
- [ ] Проверка имени: «Аню» → «алиас к «Аня»», «Ана» → «не похоже ни на одну карточку», «Аня» → «это карточка».
- [ ] «Разъединить» у «Аней» → алиас пропал из Workshop, пара в строке «Разъединены и больше не склеиваются». Следующий ответ с «Аней» уже не склеивается (DES заведёт отдельную карточку — так и задумано), под модулем предупреждение «Похоже на дубли из прошлых ответов…».
- [ ] Исключения: вписать «Аню», сохранить → проверка «Аню» показывает «в исключениях». Очистить.

### Защита от лишних склеек
- [ ] Персонаж пользователя и отдельная карточка с похожим именем не склеиваются (проверка имени показывает причину).
- [ ] При карточке «Александр» проверка имени «Александра» показывает «не похоже ни на одну карточку», а «Александру» — «алиас к «Александр»». То же для «Яна» при «Ян».
- [ ] Если в попапе DES ответить «Нет», эта пара больше не склеивается и модулем.

### Другие режимы
- [ ] Переключить DES в режим «Отдельным запросом» → под модулем предупреждение, что он работает только в режиме «Вместе с ответом». Вернуть режим.
